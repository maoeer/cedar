

# Cedar 后端管理系统

## 项目简介

Cedar 是一套完整的前后端分离的后台管理系统解决方案。该系统采用现代化的技术栈构建，前端基于 Vue.js 生态系统，后端采用 Node.js + Express 框架，数据存储使用轻量级数据库 LowDB。系统支持用户注册登录、邮箱验证等核心功能，可快速扩展以满足各类后台管理需求。

## 技术架构

### 前端技术栈

前端项目 `cedar-front-end` 采用以下核心技术构建：Vue 3 作为核心框架提供响应式组件化开发能力；Vite 作为构建工具提供极速的开发体验；Pinia 用于全局状态管理，替代了传统的 Vuex；Vue Router 处理页面路由与导航；Axios 封装 HTTP 请求实现与后端的数据交互；SCSS 预处理器提供灵活的样式编写能力。项目还包含自定义的 Toast 消息提示组件，优化用户交互体验。

### 后端技术栈

后端项目 `cedar-back-end` 基于以下技术构建：Express 框架提供简洁高效的 RESTful API 开发能力；CORS 中间件解决跨域资源共享问题；LowDB 作为本地 JSON 文件数据库，无需复杂配置即可实现数据持久化；Nodemailer 组件支持邮件发送功能，用于验证码和通知消息的推送。所有路由统一管理，支持用户管理、邮箱服务等接口扩展。

## 快速开始

### 环境要求

确保开发环境已安装 Node.js（推荐 v14 及以上版本）和 npm 包管理器。Windows、macOS、Linux 系统均可正常运行本项目。

### 后端部署

进入后端项目目录，执行以下命令完成环境搭建：首先运行 `npm install` 安装项目依赖；然后在项目根目录创建 `.env` 文件，配置服务器端口（默认 3000）和数据库路径等环境变量；最后执行 `npm run dev` 启动开发服务器，支持热重载功能。

后端服务启动后，默认监听 3000 端口，所有 API 接口均以此为基础路径提供访问。

### 前端部署

进入前端项目目录，执行以下命令完成环境搭建：首先运行 `npm install` 安装项目依赖；然后执行 `npm run dev` 启动开发服务器。Vite 提供的开发服务器支持模块热更新，可即时预览代码修改效果。

前端开发服务启动后，通常监听 5173 端口，可通过浏览器访问进行交互体验。

## API 接口文档

### 用户接口

用户模块提供用户注册、登录、信息管理等核心功能。所有接口遵循 RESTful 设计规范，返回数据采用统一响应格式。

注册接口 `POST /api/user/register` 接收用户名、密码、邮箱等参数，完成用户创建并返回注册结果。登录接口 `POST /api/user/login` 验证用户凭据，认证成功后返回登录状态和用户信息。用户信息接口 `GET /api/user/profile` 根据当前登录会话返回用户详细信息，支持权限验证。

### 邮箱接口

邮箱模块提供邮件发送和验证码验证功能，常用于用户注册验证、密码找回等场景。

发送验证码接口 `POST /api/email/send-code` 接收目标邮箱地址，生成随机验证码并发送至该邮箱，同时将验证码存储于内存中供后续验证使用。验证验证码接口 `POST /api/email/verify-code` 接收邮箱地址和验证码参数，比对存储的验证码信息并返回验证结果，验证码通常具有时效性限制。

## 配置说明

### 后端环境变量

后端项目支持通过 `.env` 文件进行配置，主要配置项包括：`PORT` 定义服务器监听端口号；`DB_PATH` 指定 LowDB 数据库文件存储路径，建议使用 `/db/db.json` 相对路径；邮件服务相关配置包括发件人邮箱地址、授权码、SMTP 服务器地址和端口等。

### 前端配置

前端项目主要通过 `vite.config.js` 进行构建配置，包括代理设置、构建输出路径、插件配置等。API 请求的基础地址可在 `src/utils/request.js` 中修改，建议在开发环境配置代理将请求转发至后端服务，避免跨域问题。

## 功能特性

本系统具备完整的用户认证体系，支持用户注册、登录、状态保持等基础功能。邮箱验证服务集成邮件发送能力，可用于多种业务场景。系统采用轻量级数据库设计，数据存储为 JSON 格式，便于备份和迁移。前后端分离架构使得项目易于部署和维护，各模块职责清晰，便于后续功能扩展。

## 开发规范

路由定义应遵循 RESTful 风格，使用标准 HTTP 方法表达操作语义。响应数据统一经过 `utils/response.js` 格式化处理，确保接口返回格式一致性。前端组件采用 Vue 3 Composition API 编写，状态管理统一使用 Pinia。代码提交前请确保 ESLint 和 Prettier 检查通过，保持代码风格统一。

## 扩展指南

新增业务模块时，后端需在 `routes/` 目录创建对应路由文件，在 `routes/index.js` 中注册路由前缀；前端需在 `views/` 目录创建页面组件，在 `router/index.js` 中配置路由映射。如需持久化新数据，在 `db/` 目录修改数据库初始化逻辑即可，LowDB 会自动创建对应数据集合。
